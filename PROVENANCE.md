# Data Provenance and Processing Scope

## Study and package identity

- Manuscript ID: `sustainability-4419983`
- Package version: 25 August 2026
- Package purpose: reproduce the statistical results reported in the AR-HUD eye-tracking manuscript from minimized, de-identified analytical inputs

## Origin of the released values

All released numerical values are derivatives of the archived experimental records analyzed for the manuscript. The package contains no simulated or synthetic participant observations.

The original eye-tracking recordings and Tobii Pro Lab project were processed in the internal analysis workflow described in the manuscript. Data minimization was then applied to release only the variables and aggregation levels required to reproduce the reported statistical analyses.

## Minimization and transformation steps

1. Participant and source-clip identifiers were replaced with newly generated pseudonyms. The released identifiers do not preserve original names, recording numbers, dates, or gaps in the source identifiers.
2. Trial-level AUC values were retained because they are required for the maneuver-level AUC tests, participant-mean sensitivity analysis, and crossed-random-intercept model.
3. Maneuver-level transition probabilities were retained without participant, clip, trial, coordinate, or timestamp identifiers. Each maneuver contributes nine transition rows, so identical released rows can represent distinct maneuvers and must not be deduplicated.
4. Participant-level transition probabilities were released only as participant-by-condition-by-scenario aggregates required for the paired sensitivity analysis.
5. Fixation-to-arrow-reference distances were released as source-clip summaries and scenario-condition frame summaries. Original frame coordinates and timestamps were not included.
6. No released data value is generated by `reproduce_statistics.py`; the script reads the packaged analytical inputs and writes statistical result tables to a separate output directory.

## Materials not publicly released

The package excludes original 120-Hz gaze streams, fixation coordinates, recording timestamps, Tobii Pro Lab project files and databases, road-video and stimulus files, calibration records, questionnaires, demographic source forms, identity mappings, and raw-data extraction code. These materials remain subject to participant confidentiality, consent, copyright, ethics, and institutional data-governance requirements.

## Validation scope

The package was tested in an isolated working directory using only the released data and code together with the listed software dependencies. This check verifies that the included derived data and code reproduce the reported numerical analyses. It is not an external independent validation of data collection, participant recruitment, apparatus equivalence to a standardized driving simulator, or ecological validity.

The authors remain responsible for the data provenance, analytical decisions, interpretation, and consistency between the package and the submitted manuscript.
